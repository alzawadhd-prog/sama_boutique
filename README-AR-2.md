# ثيم سما بوتيك لمتجر سلة
1. سجّلي في https://salla.partners وثبّتي Salla CLI: `npm i -g @salla.sa/cli` ثم `salla login`.
2. من داخل هذا المجلد: `npm install` ثم `salla theme preview` لمعاينته على متجرك التجريبي.
3. للنشر: ارفعي المجلد على GitHub واربطيه من بوابة الشركاء ← الثيمات، أو `salla theme publish`.
4. فعّليه من لوحة متجرك: المظهر ← الثيمات.
الألوان في src/assets/styles/app.css (وردي باودر ولؤلؤي).
